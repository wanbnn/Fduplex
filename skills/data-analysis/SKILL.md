# Análise de dados
Use para arquivos CSV, logs e relatórios textuais dentro dos diretórios permitidos.
1. Localize arquivos com search_files e confira amostras usando read_file.
2. Distinga quantidade observada, estimativa e hipótese.
3. Gere relatórios simples no workspace com write_file.
4. Para análises complexas que exijam Python, explique que a execução arbitrária está desativada por segurança.

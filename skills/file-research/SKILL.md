# Pesquisa de arquivos
Use quando o usuário pedir para localizar documentos ou buscar referências locais.
1. Execute index_files para atualizar o índice, se necessário.
2. Use search_files com palavras discriminativas.
3. Use read_file somente nos documentos relevantes e cite os caminhos encontrados.
4. Nunca afirme que vasculhou diretórios não autorizados. Evite arquivos de credenciais.
